# AutoCAD .NET Developer Bootcamp (C#)

Learn AutoCAD plugin development from scratch using C# and .NET.

This course is designed for engineers, CAD administrators, students, and software developers who want to automate AutoCAD workflows and build professional CAD applications.

---

## Course Objectives

By the end of this course you will be able to:

- Create AutoCAD plugins
- Develop custom AutoCAD commands
- Automate drawing creation
- Manage layers programmatically
- Create and insert blocks
- Work with attributes
- Query and modify existing objects
- Build real-world engineering productivity tools
